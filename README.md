# Machine Learning (Portfolio)

A personal portfolio repo of machine learning projects, experiments, and notes - focused on **practical, end-to-end workflows** (data → EDA → modelling → evaluation → iteration) using Python and Jupyter.

The goal is to keep projects **clean, reproducible, and explainable**

---

## What you’ll find here

- **Project notebooks** showing exploratory analysis, feature engineering, modelling, and evaluation
- **Reusable Python code** for common tasks (loading data, preprocessing, training, metrics)
- A growing set of **learning exercises** as I expand breadth across supervised learning, time series, and more


> - Folders are arranged by the type of machine learning technique being used
> Most projects are built with: `pandas`, `numpy`, `matplotlib`, `scikit-learn` (and occasionally PyTorch for deep learning application).
> I also dedicate a portion of my time getting to grips with the mathematical foundations of modern ML techniques. You can see this in the ML_from_scratch folder, where I am working on ML algorithms without importing libraries.
